4. CAPTCHA Solver (NopeCHA) — optional, off by default


Without a key the bot stops on a CAPTCHA / Cloudflare challenge. With a key pasted here (or NOPECHA_API_KEY in .env) and the toggle on, it attempts one solve per challenge page (Token API for reCAPTCHA v2/v3 + Turnstile). Solving a CAPTCHA may violate Viagogo's terms and increases account-ban risk, and NopeCHA does not guarantee a solve — a Cloudflare interstitial (no sitekey) cannot be solved at all. Get a key at nopecha.com (free tier: 100 recognitions/day; Starter $4.99/month). The key is stored in the local database, shown back only masked, and never logged.
