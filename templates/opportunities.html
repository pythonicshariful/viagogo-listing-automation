What this is: the scanner monitors watched Viagogo events, scores each one (market price, recommended price, estimated profit, demand, risk, confidence, best timing) with transparent heuristic rules — see README § Opportunity Scanner. It does not predict the future: there is no ML model yet, because no historical data exists. Scans store price snapshots so a future ML model has training data. Sample data: mock scans use labelled sample numbers, not live market data — do not act on them. Live scans need SCAN_LIVE=True.

CAPTCHA Solver (NopeCHA)

Optional, off by default. Set it up on the main page, section 4: paste your NopeCHA API key there and enable it — the scanner then attempts one solve per challenge page. Without a key, a challenge stops that event's scan (recorded as live-challenge).
